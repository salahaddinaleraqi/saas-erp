# SaaS ERP Architecture

## Vision

Build a modern cloud-native ERP system using Django and Django REST Framework as the backend and a modern JavaScript frontend.

The system is designed to be:

- Multi-tenant
- Modular
- API-first
- Secure
- Scalable
- Maintainable

---

## Backend

Python 3.14

Django

Django REST Framework

SQLite during development

PostgreSQL in production
